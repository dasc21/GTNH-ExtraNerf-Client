# GTNH 2.9.0 + Extra Nerf — Клиент сервера

Публичная страница клиентской сборки для будущего сервера GTNH 2.9.0 + Extra Nerf.

> **Статус: тестирование.** Публичная стабильная клиентская сборка ещё не выпущена. Не скачивайте случайные тестовые JAR как готовый клиент.

## Скачать

Когда сборка пройдёт испытания, ZIP для PrismLauncher и файл контрольных сумм появятся в разделе **Releases** этого репозитория.

## Установка

См. [INSTALL.md](INSTALL.md). На Windows с двумя GPU (Intel + NVIDIA) для устранения графических артефактов может потребоваться назначить дискретную GPU исполняемому `javaw.exe` в настройках графики Windows.

## Ошибки и пожелания

Используйте GitHub Issues. В отчёт об ошибке добавляйте версию релиза, шаги воспроизведения и обезличенный фрагмент лога, **не** публикуйте пароли, токены, персональные данные, полный `server.properties` или координаты приватных баз.

## О распространении модов

Прежде чем выкладывать полный архив, необходимо проверить лицензии каждого мода и способ легальной дистрибуции. Если права запрещают переупаковку, предпочтителен манифест установки (со ссылками на первоисточники) плюс отдельно разрешённые собственные патчи.

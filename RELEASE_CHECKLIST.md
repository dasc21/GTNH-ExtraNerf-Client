# Checklist: публикация клиентской сборки

- [ ] Клиент соответствует версии выделенного сервера и Extra Nerf.
- [ ] Проверены лицензии и ограничения на перераспространение всех JAR/ресурсов.
- [ ] Отдельно проверены клиентские и серверные зависимости.
- [ ] Гарантировано отсутствие аккаунтов, токенов, паролей, saves, приватных логов.
- [ ] Проверена установка из нового профиля PrismLauncher и запуск Windows/Linux (при наличии тестеров).
- [ ] Пройден Extra Nerf audit и проверены критичные рецепты.
- [ ] Пройдены тесты совместимости и стабильности выделенного сервера.
- [ ] Сформирован manifest с версией, временем сборки, списком компонентов и SHA-256.
- [ ] В Release размещены ZIP и `SHA256SUMS.txt` с информацией о версии и известных проблемах.
- [ ] Снимок релиза и совместимый архив для отката сохранены в закрытом Google Drive.

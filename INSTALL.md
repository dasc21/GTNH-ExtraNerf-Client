# Установка клиента

**Пока нет публичного релиза:** эта инструкция действует только после публикации релиза.

1. Установить актуальный PrismLauncher.
2. Открыть **Releases** и скачать клиентский архив, помеченный Stable, а также \`SHA256SUMS.txt\`.
3. Проверить SHA-256 скачанного архива (Windows PowerShell: \`Get-FileHash -Algorithm SHA256 .\<архив>.zip\`).
4. Импортировать ZIP в PrismLauncher через **Добавить экземпляр → Импорт из ZIP**, если архив действительно сформирован как переносимый экземпляр Prism/MultiMC.
5. Использовать рекомендованную для конкретного релиза Java и память (они будут указаны в релизе).
6. Если мир мерцает или видны чёрные треугольники, в **Windows → Настройки → Дисплей → Графика** выбрать высокопроизводительную NVIDIA для того \`javaw.exe\`, который использует этот экземпляр.
7. Запустить игру и подключиться по адресу, опубликованному в описании стабильного релиза.

Не переносить из тестовой сборки личные аккаунты, токены, сохранения или устаревшие моды вручную.
